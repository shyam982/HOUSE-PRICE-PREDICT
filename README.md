# NovaNest Property Intelligence

A modern house price prediction dashboard built with HTML, CSS, and JavaScript. It provides an interactive experience for estimating property values using a lightweight regression-inspired pricing model, market scenario insights, and a polished visual interface.

## Features

- Interactive property input controls for bedrooms, bathrooms, area, age, neighborhood, and growth outlook
- Dynamic price estimation with a premium-style UI
- Scenario explorer for balanced, renovation, and growth-surge market views
- Live forecast chart and investment insights
- Light/dark theme toggle

## Project Structure

- index.html — Main app layout
- styles.css — Styling and responsive design
- script.js — Prediction logic, chart rendering, and UI interactions
